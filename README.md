# Landing page: Super Mario Bros. O Filme

Página de apresentação do filme *Super Mario Bros.*, feita para praticar HTML, CSS e JavaScript.

## O que tem na página
- Vídeo de fundo em tela cheia, tocando em loop e sem som.
- Cabeçalho com logo e menu.
- Botão que abre o trailer do YouTube numa janela (modal) e para o vídeo ao fechar.
- Layout responsivo para celular (`src/css/responsivo.css`).

## Tecnologias
- HTML5
- CSS3 (Flexbox e media queries, fonte Poppins do Google Fonts)
- JavaScript puro (abre e fecha o modal do trailer)

## Como ver
Abra o arquivo `index.html` no navegador. Para publicar, ative o GitHub Pages em **Settings > Pages > Branch: main** e a página fica em `https://g4vo-dev.github.io/projeto-mario/`.

## Estrutura
```
index.html
src/css/       reset, estilos e responsivo
src/js/        modal do trailer
src/imagens/   logo, título e personagens
src/videos/    vídeo de fundo
```
